FAQ

Perguntas frequentes

O Free tem limitação de tempo?+
Não. O plano Free é gratuito para sempre — sem expiração, sem solicitar cartão. A única limitação é o número de projetos ativos (1 projeto).
Meus dados ficam em qual servidor?+
Nenhum. Todos os dados são salvos localmente no seu computador via IndexedDB — o mesmo mecanismo usado por bancos de dados de apps nativos. Não há transmissão de dados para servidores externos.
Como recebo a licença após o pagamento?+
Após a confirmação do pagamento, a chave de licença é enviada automaticamente por e-mail em até 5 minutos. Você insere a chave na primeira vez que abrir o software.
O software funciona em Mac ou Linux?+
Atualmente o instalador é para Windows 10/11 (64-bit). Versões para Mac e Linux estão no roadmap para 2025.
O que acontece quando o ano de atualizações termina?+
O software continua funcionando normalmente — a licença é perpétua. Apenas atualizações para versões futuras requerem renovação anual opcional (50% do valor da licença).
Posso instalar em mais de um computador?+
A licença Professional permite instalação em até 2 máquinas por usuário. O plano Enterprise permite instalação em toda a empresa.
